# INECOBANK — редизайн сайта · PM-кейс

Инициативный проект: редизайн сайта [inecobank.am](https://inecobank.am) для русскоязычной аудитории.

**Живой сайт:** https://inecobank-ru.vercel.app  
**PM-питч:** https://inecobank-ru.vercel.app/pitch

---

## Что это

Работающий прототип нового digital-канала привлечения клиентов INECOBANK.

Сделан как PM-кейс: каждая фича — продуктовое решение с обоснованием.
Реализован за 3 часа, без команды и дизайнеров.

## Что реализовано

- Главная страница с квизом подбора продукта (3 вопроса → персональная рекомендация)
- Страницы продуктов: карты, кредиты, депозиты, ипотека, переводы
- FAQ с категориями и аккордеоном
- Поиск и фильтры отделений
- О банке, 404
- Toast-уведомления на все CTA-кнопки
- PM-питч с воронкой, метриками и продуктовыми гипотезами

## Стек

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Vercel

## Запуск локально

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000)
